# ロードマップ

構想は、神経回路・感覚・筋肉・身体・内部状態が結びつくシミュレーションです。現在はショウジョウバエの歩行が最初の課題です。F01〜F16は研究版の受入目標であり、公開パッケージの完成保証ではありません。

| 優先 | 作業 | 終了条件 |
|---|---|---|
| 1 | 導入とデータ準備 | 個人PCの内部パスに依存せず不足物が分かる |
| 2 | 公開CPG陽性対照 | 小さな既知回路のリズムと遮断対照を再現 |
| 3 | 筋肉・身体の陽性対照 | 同一の筋腱で支持・遊脚・推進を確認 |
| 4 | 神経と身体を接続 | 募集、位相、力の方向、滑りを照合 |
| 5 | 自律歩行 | 外部歩行命令なし、六脚の接地反復と3体長移動、受入5試行中4試行 |
| 後続 | 感覚、内部状態、学習、飛行 | 各条件と遮断・保存再開を別々に検証 |

未同定5運動出力の均等配分候補は保留です。失敗試行では未発火で、不前進を直接説明しません。最終受入で必要な出力の対応は確認しますが、数値を埋めるために仮定を足しません。

失敗が続く場合は全CNS探索を止め、原因を分離できる試験へ戻ります。達成の見込みや期限は保証しません。
