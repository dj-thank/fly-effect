# 理念と研究上の責任

Fly Effectの目的は、神経系・身体・環境が結びつく仕組みを、検査可能な計算モデルとして理解することです。限られた資源でも、小さく再現できる実験を積み重ねれば、世界中の人が検証・改善に参加できます。

出発点はショウジョウバエです。他の生物への一般化は将来の可能性で、現在対応しているという意味ではありません。

基礎科学や教育を通じ、将来の医学・工学研究へ役立つことを願っています。現在のソフトウェアは診断・治療の製品ではなく、患者データや臨床判断を扱う機能も提供していません。

神経発火があること、物理モデルが動くこと、行動条件を満たすこと、生体と一致することは別々に評価します。仮定は名前と出典を付けて残し、計算結果から言える範囲を超えて主張しません。

公開データを優先します。人や動物を対象とする新たな研究は、このコードの利用だけで承認されるものではありません。必要な審査・同意・権利確認は各研究の責任で行います。公開Issueに患者情報、個人情報、認証情報を投稿しないでください。

運営理念とライセンス上の利用許諾は分けます。研究成果への批判、再現しない結果、異なる仮説を歓迎します。
