# FE-02: 自由基部のばね・減衰を除く同条件比較

基点はPR #14の `eb164fa4732e45b4542070aa225df3cf3080efb2`。
[Issue #4](https://github.com/dj-thank/fly-effect/issues/4) とPR #15の事前計画を実装する、独立した機械系比較です。コードやCIの成功は支持・歩行の達成を意味しません。

## 今回の問いと不変条件

`legacy_anchored` の自由基部は stiffness=0.4、6自由度の damping=0.02。
`unanchored_root_candidate` はこの2項目だけを0にします。armature=1e-6、frictionloss=0、脚、質量・慣性、筋腱、力上限、ソルバ設定を維持します。ばねと減衰を同時に除く介入なので、動的な差を片方だけの効果とは認定しません。armatureを残しているため、あらゆる人工的設定が除去されたモデルとは呼びません。

既存 `Body` の生成経路・既定値・神経統合は変更しません。検証済み90腱XMLから新しいXMLを生成してコンパイルし、変更を許す配列はroot部分の `jnt_stiffness` と `dof_damping` だけです。全公開compiled配列とソルバ設定を照合し、想定外の差を拒否します。原XML、登録記録、メッシュ、チェックポイントを書き換えません。

派生モデルは別フォルダー・別ID・新しい `model-receipt.json` を持ちます。腱の位置合わせ自体を再推定するのではなく、元の登録を保持し、腱・site配列の同一性を確認してroot-only変換履歴を追加します。旧モデルのIDを新モデルへ付け直す機構はありません。

## 実行と固定条件

Linux /procが必要です。依存導入は実験の時間予算外です。

```bash
python -m pip install -e ".[body,mechanics]"
python scripts/run_root_ab_study.py --workspace work/root-ab-new
```

既存workspaceは拒否します。既存のsource audit、90腱登録、mechanical studyを同一workspaceで再生成します。そのrun内のlegacy記録姿勢を両条件へ同じゼロ速度・同じ数値履歴で渡します。条件ごとに別々に静止させた姿勢は比較しません。過去artifactの別環境のbody hashを無理に書き換えて復元する方法でもありません。

非接触の並進・非ゼロ速度の解析対照は、ばね成分と減衰成分を個別に検算します。重力や全加速度が0になることを期待しません。座標設定は一瞬の診断配置であり、歩行時の位置強制ではありません。

記録姿勢の支持・力会計、既存9姿勢×5深度の走査、4条件それぞれ250msの人工張力試験を両モデルで実行します。静的支持、接触の意味、力上限、数値許容誤差は既存実装を再利用して変更しません。静的解を持つ場合の追加試験は別の動的保持計画へ分け、この比較は4条件に固定します。

姿勢走査は120秒、各条件subprocessは180秒、準備を含む全工程は600秒が上限です。Linux supervisorは子プロセス群と自身の合計RSSを50ms間隔で監視し、8192MiBを超えたら全子プロセス群を終了します。共有ページは重複計上します。監視間隔内の一時的超過を完全に防ぐhard aggregate capではありません。追加で各workerの仮想アドレス空間を8192MiBに制限します。ソルバが内部で長引いても外側の期限で終了します。新しいサービス、常駐処理、課金実験は追加しません。

## 証拠と判断

`protocol.json` は測定前のコードハッシュ・保護ファイル・固定条件、各条件のreceipt/result/NPZはモデルと生の観測、`comparison.json` は同条件照合、`pipeline-result.json` は資源・失敗を記録します。完了時にコードと保護ファイルの再照合を行います。NaN/Infinityを結果JSONへ保存しません。

比較器は開始姿勢・積分状態・腱長・力上限・接触行列・支持行列・時間列を照合します。試験途中で停止した250ms未満の記録、同じように間違った開始姿勢、未知/不正なソルバ結果を成功として扱いません。

- 有効な比較で固定姿勢群の支持成立0件: その条件内の否定的結果。次に前・中・後脚の配置または力方向を別の事前登録試験で切り分けます。
- 静的支持成立: 別の動的保持試験へ進みます。立位や歩行の認定はしません。
- 時間・メモリ制限: 判定不能。依存不足: 環境阻害。比較不整合: 計測修正を優先します。

CIはソースXML・外部メッシュをartifactへ入れず、JSON/NPZ/logを14日保管します。第三者検証ではartifact digest、NPZ hashと配列、力会計、開始状態、保護ハッシュを個別に再計算します。期限付きartifactだけを恒久記録とせず、検証後の小さな結果・ハッシュをIssue/PRへ残します。

一次仕様: [MuJoCo freejoint](https://mujoco.readthedocs.io/en/stable/XMLreference.html#body-freejoint)。既定値の継承を避けるfreejointの説明がありますが、この実験ではarmatureまで一括変更せず、宣言した2項目だけを比較します。
