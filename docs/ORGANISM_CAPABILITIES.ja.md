# 生命・意識へ向けた研究目標

[English](ORGANISM_CAPABILITIES.md)

**Fly Effectの長期目標には、計算基盤における生命や意識そのものの成立に到達することを含めます。** 実現できるか、どのような条件で成立し得るかを研究します。記憶・恒常性・自己維持は、その目標を置き換える終点ではなく、中間段階です。

現在その能力があるという宣言ではありません。F01〜F16の完成、行動試験の成功、チェックポイント保存だけから、生命や意識の成立は結論できません。

## 目標と証拠を分ける

機能としての記憶・状態調節・予測的回避は、モデルの動作として測定します。生命は、自己維持・組織化・適応など、採用する定義と満たす条件を明示して検討します。意識は複数の理論に基づく指標、介入、反証を記録し、チェックリストや自己申告だけで成立判定を自動化しません。[生命の定義の背景](https://science.nasa.gov/universe/search-for-life/life-on-other-planets-what-is-life-and-what-does-it-need/) / [意識指標の研究](https://pubmed.ncbi.nlm.nih.gov/41219038/)

## 添付設計から採用する方向

環境→外受容→神経回路→行動→身体→内部状態→内受容・神経修飾→局所可塑性→次の行動、という循環を目指します。

内部状態はenergy、hydration、damage、fatigue、sleep_pressureを初期の語彙とします。単位・範囲・消費・回復則を仮定と実測に分けます。人が観測する画面に値を表示することは構いませんが、別の行動選択器がその値を直接読んで神経回路を迂回しない構造にします。

食物に触れただけで回復させず、神経・運動経路による摂取の証拠と資源量の収支を結びます。基礎消費や筋活動のコストを明示し、負の機械的仕事から勝手にエネルギーを作らないようにします。恒常性の目標には、理由のない一点との対称的な誤差より、根拠のある生存可能範囲を使います。

身体状態による行動調節には生物学的な背景がありますが、5変数を置くだけで生理を再現したことにはなりません。単一のドーパミン信号への集約も仮説として扱います。[身体状態とキノコ体](https://pubmed.ncbi.nlm.nih.gov/38876486/) / [ペプチド性調節](https://pubmed.ncbi.nlm.nih.gov/39956367/)

記憶は、まず1区画の実KC→MBON接続とDANを選び、基底配線を保持したまま、制限された可塑性差分を保存します。短期・長期の2配列を置けば実際の記憶回路になるわけではありません。局所則を検証してから固定化や回路間相互作用を追加します。[短期・長期記憶研究](https://pubmed.ncbi.nlm.nih.gov/39038490/)

内部状態から学習信号を作る方法も、広い意味では強化学習に含まれ得ます。重要なのは名称ではなく、外部の運動方策で実回路を置き換えないことです。[恒常性と学習の展望](https://arxiv.org/abs/2507.04998)

## 受入試験の仕様

以下は未実装の試験計画で、合格済みの能力ではありません。

- **記憶:** 対提示・非対提示、可塑性停止、記憶リセット、短期状態の洗い流しを比較。保存再開後にも効果が残るか調べる。
- **恒常性:** 未知環境で生存可能範囲の維持・回復を測り、内受容遮断・資源なしの対照と比較する。期間、効果量、seed、予算は実験前に固定する。
- **自己維持:** 危険を予告する手掛かりからの回避、活動可能時間、空腹などによるリスクの変化を、未学習・sham・経路遮断と比較する。望む回避行動を直接プログラムして結果にしない。
- **個体A/B:** 同じ初期配線・パラメーターから異なる経験を与え、試験時の内部状態・一過性の神経状態・乱数・環境を揃えて記憶の効果を分離する。現在は遺伝子型をモデル化していないため「同じ遺伝的状態」とは表記しない。
- **生命・意識:** 機能試験とは別の研究記録で、理論、指標、代替説明、反証、解釈の限界を継続して評価する。

自己維持は仮想環境内での行動です。実験者による停止・リセット・保存・再開を妨げたり、勝手に複製・計算資源取得を行ったりする意味ではありません。

## 実装への分解

[10件の公開Issueと依存関係](PROJECT_OVERVIEW.ja.md)を整理しました。[プログラム仕様](../specs/organism-program.json)に受入条件とIssueリンクがあります。公開CPGと同一身体の陽性対照を基礎にし、状態会計と局所記憶は限定した単体研究として並行して準備できます。身体行動の主張は、その前提となる神経・物理経路を確認してから行います。

既存のMaleCNSはすでに脳と腹側神経索を含みます。添付にあるFlyWire/BANCの知見を参照しても、実IDを混同したりデータセットを黙って切り替えたりしません。[脳と神経索の研究](https://www.nature.com/articles/s41586-026-10735-w)

生命や意識まで目指すという目的は維持します。ただし「必ずできる」「指標を満たしたから成立した」という結論を先に置かず、実装・対照試験・研究の蓄積から判断していきます。
