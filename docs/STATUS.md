# 現在の状態

## 2026-09-15：張力権限マージン診断（未マージ・構造的欠損を確定）

反復シフトの収縮極限で全支持残差が~0.2に停滞し張力がfmaxに飽和していたため、全273保存証人（配置9+姿勢探索144+指向シフト22+反復98）について「全行厳密・摩擦不変・張力上限のみスカラーsで緩和」するLPを再生しました。
結果は **`unbounded_tension_deficit`：全証人が「いかなる有限の張力倍率でも不可行」** — 筋力不足ではなく、張力が届かない行（root並進 0-2 + 受動 30、張力マップが厳密にゼロ — root回転3-5には張力が届く）を接触錐が厳密に覆えない構造的限界です。`evidence_valid: true` で全LP再生一致。
これでFE-02の欠損分解が完成：接触+root釣り合いは達成可能、受動行は漸近接近（~1e-7残差）するも厳密には未到達、筋力はボトルネックではない。残る lever は姿勢/接触生成のみ。動的保持・立位・歩行・全脳実行の主張はありません。

残差降下姿勢生成（FE-02-residual-descent-v1、4収縮種子）も実施：受理移動は**全て実動DOF**（未探索空間が実際に降下方向を持つことを確認）するも、固定接触写像の残差床は非ゼロ（候補2で~5e-6、候補1は予算打切り2.1e-4）、物理認証はgate 2止まりで `descent_floored_without_feasibility`（検証見解はseed初期LP未決により `inconclusive`）。**接触構成そのものが束縛条件**であることが確定 — 次の正当な方向は接触点を変え得る生成器。

## 2026-09-15：マージン方向への反復姿勢シフトを実施（未マージ・収束せず）

物理シフト後の保存証人で必要シフト量が収縮する候補（候補1: t 0.0017→0.0001）が見つかったため、評価→マージンLP→シフトのループを系統あたり最大6回・種子2個ずつ（18系統）反復する実験を実施しました。
結果：候補1–2は t が幾何級数的に収縮（候補1: 1.7e-3→7.2e-12）しながら厳密な受動平衡には到達せず反復上限で停止、候補3–9はマージン増大またはroot釣り合い喪失で早期停止。記録見解は `no_convergence_in_bounded_iteration`。
ただし非駆動の深部サンプル4箇所のLPが数値的に未決のため、fail-closedの検証済み見解は `inconclusive` です。各線形化ステップがその計算に使った接触幾何を再び乱すため、収縮は漸近的で有限回では到達しない構造が示されました。
受動部分系・全支持に届いたサンプルはなく、動的保持・立位・歩行・全脳実行の主張はありません。

## 2026-09-15：δ*方向への物理姿勢シフトを実施（未マージ・平衡未到達）

結合マージンで権限内と判定された全133証人について、受動関節を `q'_d = q_d + δ*_d/k_d` へ実際に動かし、変化した接触幾何の下でゲート列を再評価しました。
結果は `no_shift_reached_equilibrium`：受動部分系に届いた姿勢はなく、シフトが接触構成を乱してroot釣り合いすら崩れる場合が多数（候補6–9ではfoot-only接触を失う試行も）。
代数スクリーンの「権限内」と物理結果の差は、接触行列・biasの姿勢依存そのものであり、ばねシフト方向が接触幾何と絡み合っていることが定量化されました。動的保持・立位・歩行の主張はありません。

## 2026-09-15：受動ばね権限の結合マージン診断（未マージ・権限内）

姿勢探索の単一行スクリーンでは解消不能だったroot＋受動行矛盾について、全30受動行のばねシフトを**同時に**達成可能区間内で動かす結合権限LPを、保存済み153証人に再生しました。
結果は `within_combined_authority`：全9候補に権限内（t≤1）の証人があり、最良は権限区間の0.17%。矛盾は権限不足ではなく協調の問題であり、次の物理姿勢生成の照準となる必要シフト方向を保存しました。
固定幾何の代数スクリーンであり、実際の姿勢移動は接触行列も変えるため物理的平衡の証明ではありません。動的保持・立位・歩行・全脳実行の主張はありません。詳細は[受動姿勢の検証](PASSIVE_POSTURE.md)を参照してください。
