# HAE exhibition replay

This public review package serves the saved `f06-seed1-closed-loop-10s`
recording. The project owner authorized publication through a reviewable pull
request on 2026-09-22.

- `replay.html` plays the ten-second saved video and synchronized recorded contact, CNS spike, sensory-event, force, and body-position series.
- The page supports play/pause, 0.25x/0.5x/1x/2x, and frame seeking.
- GPT-Live synthetic audio has launched the dedicated Edge replay, advanced the real video to 0.51 seconds, read synchronized values, stopped the exact owned process tree, and returned to the ten-exhibit list.
- This is recorded replay evidence. It does not prove a new live simulation, free autonomous six-leg walking, five required motor units, twelve tendons, biological calibration, physical audio, or Human acceptance.

The MP4, PNG, and replay values are transformed outputs of an uncalibrated
simulation. They are not raw biological observations. Read `NOTICE.txt`,
`PROVENANCE.md`, `SOURCE_ATTRIBUTIONS.json`, `LICENSES/Apache-2.0.txt`, and
`LICENSES/CC-BY-4.0.url.txt` before redistribution. Fly Effect MIT covers the
original viewer code only; it does not relicense FlyGym/NeuroMechFly geometry
or MaleCNS/MANC-derived values.

`observation.npz`, the absolute-path `body.xml`, raw tables, raw meshes, and
encoder binaries are deliberately excluded. This directory remains
